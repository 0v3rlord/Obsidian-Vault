- **WHOIS** is a query and response protocol designed to access databases about registered internet resources.
- Standardized in **RFC 812**.
- [Historical WHOIS Data](https://whoisfreaks.com/)
- **Bulletproof Hosting Provider**: Often used for malicious activities.
##### WHOIS Records Typically Contain:
- Domain Name
- Registrar
- Registrant Contact
- Administrative Contact
- Technical Contact
- Creation and Expiration Dates
- Name Servers

## Utilizing WHOIS
### Scenarios:
- Phishing Investigations
- Malware Analysis
- Threat Intelligence Report
