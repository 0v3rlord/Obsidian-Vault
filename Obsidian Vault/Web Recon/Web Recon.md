- **Web Reconnaissance** is the foundation of a thorough security assessment.
- Preparatory phase before delving deeper

### Primary Goals of Web Recon
- **Identify Assets**: Discover all publicly accessible components such as web pages, subdomains, IP addresses, and technologies.
- **Discover Hidden Information**: Locate sensitive info such as backups, configs, or internal docs.
- **Analyze Attack Surface**: Assess technologies used, configs, possible entry points for exploitation.
- **Gathering Intelligence**: Gather information that can be used for further exploitation or social engineering, such as key personnel, email addresses, or patterns in behavior.

# Why [[DNS]] Matters for Web Recon
- Uncovering Assets (ex. a CNAME record pointing to an outdated server)
- Mapping the Network Infrastructure. (ex. NS record can reveal hosting provider)
- Monitoring for Changes. Continuously monitoring DNS can reveal changes in infrastructure.
